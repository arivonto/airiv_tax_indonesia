AIRIV Indonesia DJP Coretax Rail

Indonesia DJP Coretax & e-Faktur Tax Engine

Statutory Indonesian taxation layer for Odoo 18 with PPN 12%, DPP Nilai Lain, 16-digit NPWP/NIK validation, NSFP allocation, and e-Faktur/Coretax CSV export.

Core Capabilities

AIRIV Tax Indonesia adds Indonesian commercial taxation controls to Odoo with partner tax identity data, invoice tax references, NSFP pools, and e-Faktur export workflows.

Coretax Identity

NPWP/NIK 16 digit validation

Store Indonesian taxpayer type, NPWP 16 or NIK, NITKU, registered tax name, and official tax address on contacts.

Invoice Tax Control

NSFP and transaction code

Assign Faktur Pajak numbers to customer invoices and track e-Faktur status through the accounting workflow.

Export Rail

e-Faktur/Coretax CSV

Generate DJP-oriented CSV export data for approved customer invoices, including FK and OF rows.

Feature & Workflow Automation

1

Configure tax master

Install Indonesian tax records such as PPN 12%, DPP Nilai Lain, and PPh 23 tax definitions.

2

Prepare partners

Fill taxpayer type, NPWP/NIK 16 digit, NITKU, official tax name, and official tax address.

3

Assign NSFP

Create an active NSFP pool and let customer invoices receive sequential Faktur Pajak numbers.

4

Export e-Faktur

Use the export wizard to generate CSV files and update invoice e-Faktur status.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, add the module folder to your addons path, restart Odoo, update the apps list, and install the module.

Configure

Prepare tax identity data

Review Indonesian tax records, fill partner NPWP/NIK 16 digit, and create active NSFP ranges.

Operate

Assign and export

Post customer invoices, assign NSFP, then use the e-Faktur export wizard for the selected tax period.

Configuration Checklist
